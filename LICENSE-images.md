# Image licences

Images in `images/` come from openly licensed sources, mainly Wikimedia Commons. Each image keeps its original licence (for example CC BY-SA 4.0), not the licence of this repository.

- Each image's author, licence and source link are listed in `data/image-credits.json` and shown under the image in the guide.
- Images were resized and converted to WebP. No other changes were made unless the credits file says otherwise.
- Images whose reuse terms aren't clear are not used.
